# Water Level Indicator

## Project Overview

This project is a browser-based simulation of a water level indicator. The user can increase or decrease the simulated tank level using buttons. The page displays the water level as a percentage and shows whether the level is low, medium, or high.

This version is a software simulation. It does not connect to a physical water sensor or control a pump.

## Features

- Displays a tank with a visual water level.
- Shows the level as a percentage.
- Provides increase and decrease buttons.
- Displays low, medium, and high level indicators.
- Runs locally in a web browser.

## Technologies Used

- HTML
- CSS
- JavaScript

Level Ranges
Level	Indicator
0%	Tank is empty
1–39%	Low
40–79%	Medium
80–100%	High


How It Works
JavaScript stores the tank level in a variable. Each button changes the level by 10%, keeping it between 0% and 100%. The display updates the water graphic, percentage, status message, and matching level indicator.

CSS controls the page layout, tank appearance, water color, and indicator lights.
Possible Improvements
- Add a physical water sensor and microcontroller.
- Display readings from an Arduino or ESP32.
- Add an alarm when the tank reaches a chosen level.
- Add pump control in a hardware version.
